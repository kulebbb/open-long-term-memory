# Repository instructions

This repository is the public framework and demo for Open Long-Term Memory.

- Never add real personal, customer, or organizational memory.
- Use fictional `example-*` or `sample-*` records for demonstrations.
- Never add credentials, private URLs, contact details, or other secrets.
- Keep the indexer dependency-free and compatible with Python 3.9+.
- Keep synchronization compatible with POSIX `sh`.
- Do not hand-edit generated blocks in `INDEX.md` or `moc/*.md`.
- Run `make check` before declaring a change complete.
- Commit messages may be written in English or Chinese; keep them focused.
